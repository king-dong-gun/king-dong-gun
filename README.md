🧑‍💻 About Me
Spring Boot를 중심으로 백엔드 개발과 서비스 운영을 경험했습니다.
실무에서는 레거시 서비스 유지보수, 데이터 이슈 대응, 외부 API 연동, 인증/인가 기능 개발과 함께
Nginx 설정, SSL 인증서 적용, 서버 배포 등 서비스 운영에 필요한 업무도 함께 수행했습니다.
단순히 기능을 구현하는 것보다 서비스가 실제 운영 환경에서 안정적으로 동작하도록 만드는 과정에 관심이 있습니다.
기존 시스템을 이해하고 필요한 기능을 추가하거나, 데이터 흐름과 인증 구조를 정리하면서 발생하는 문제를 해결하는 경험을 쌓았습니다.
현재는 SSAFY에서 Python 기반 알고리즘과 AI를 학습하며
기존 Java/Spring 백엔드 경험에 문제 해결 능력과 새로운 기술 역량을 더하고 있습니다.
🛠 Development
- Backend Development
  Spring Boot 기반의 서비스 기능 개발과 기존 레거시 시스템 유지보수를 경험했습니다.
- Authentication & Authorization
  Spring Security, JWT, OAuth 2.0을 활용한 인증/인가 기능을 구현하고 사용자 유형에 따른 접근 제어를 다뤘습니다.
- API Integration
  공공데이터포털, VWorld 등 외부 API를 연동하고 수집 데이터를 내부 서비스와 연결하는 작업을 수행했습니다.
- Database & Data Handling
  MySQL, PostgreSQL을 사용해 데이터를 관리하고 데이터 정합성 확인, 쿼리 수정, 인덱스 최적화 등을 경험했습니다.
- Service Operation
  Nginx 라우팅, SSL 인증서 적용 및 갱신, 서버 배포, 버전 관리 등 서비스 운영 업무를 수행했습니다.
